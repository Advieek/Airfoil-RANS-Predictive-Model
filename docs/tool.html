Predict a flow field

Pick an airfoil and flow conditions. Prediction runs entirely in your browser — no server, no network call after the page loads.

Runs the MLP, not the GraphSAGE model that wins on the Results benchmark — GraphSAGE's accuracy depends on matching the point density it trained on, and this page generates a synthetic point cloud that doesn't match any AirfRANS mesh, which measurably hurts it. The MLP has no such dependency, and is also the model this fully-static build can run (GraphSAGE needs a k-NN graph rebuilt around a live point cloud, which is a bigger port not done here).
